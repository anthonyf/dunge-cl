## Why

The `run-combat` function in `game/combat.scm` has a parameter named `enemy-name` that shadows the `enemy-name` record accessor generated by `(define-record enemy ...)`. Inside the combat loop, the string interpolation `$(enemy-name e)` expands to `(enemy-name e)` — which calls the string `"Goblin"` as a function instead of the accessor, crashing with `The value "Goblin" is not of type LIST`. This breaks combat on every invocation when the stats display is reached.

## What Changes

- Rename the `enemy-name` parameter in `run-combat` to avoid shadowing the `enemy-name` record accessor
- Update all references to the parameter within `run-combat`
