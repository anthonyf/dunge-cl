## MODIFIED Requirements

### Requirement: Combat stat display uses interpolation
- **WHEN** combat stats are displayed during an active encounter
- **THEN** enemy and player stats SHALL be rendered using string interpolation with record accessors, and function parameters SHALL NOT shadow record accessor names generated by `define-record`

#### Scenario: Enemy stats display works inside run-combat
- **WHEN** `run-combat` displays enemy stats using `$(enemy-name e)`
- **THEN** the expression SHALL call the `enemy-name` record accessor (not the function parameter) and display the enemy's name correctly
