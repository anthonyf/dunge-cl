* Dunge

A text adventure engine built in Common Lisp, playable in the terminal or browser.

[[https://anthonyf.github.io/dunge-cl/][Play in your browser]]

** Overview

Dunge is a solo RPG text adventure using [[https://cairnrpg.com/cairn-srd/][Cairn]] mechanics — three stats (STR/DEX/WIL), automatic damage with armor reduction, and critical damage via HP→STR spillover. Players create a character, choose a background, and explore a choice-based world with combat encounters.

The engine supports two UI contexts from the same codebase:
- *Terminal REPL* — synchronous read-line loop via SBCL
- *Browser* — event-driven DOM rendering via JSCL cross-compilation to JavaScript

** Quick Start

#+begin_src bash
make run       # Terminal REPL
make build     # Web build (produces dist/)
make test      # Run tests
make test-web  # Web test build + Playwright
make test-all  # Run both test and test-web
make clean     # Remove ASDF cache, .fasl files, dist/, test-results/
#+end_src

** Dependencies

- [[https://www.gnu.org/software/make/][GNU Make]] — build automation
- [[https://www.sbcl.org/][SBCL]] — Common Lisp compiler
- [[https://github.com/fukamachi/qlot][Qlot]] — project-local CL dependency manager (installs Alexandria, Rove, etc.)
- [[https://github.com/jscl-project/jscl][JSCL]] — CL-to-JavaScript compiler (vendored in =vendor/jscl/=)
- [[https://nodejs.org/][Node.js]] + [[https://playwright.dev/][Playwright]] — browser tests only (=npm install=)
