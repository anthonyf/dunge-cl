# Adaptation Testbed Provenance

This example is an original Dunge testbed scaffold. It does not copy text,
tables, art, layout, or trade dress from the researched games.

## Sources Considered

- [The Elf Game](https://osrelfgame.itch.io/eg): public-domain rules reference
  candidate.
- [The White Beast of Sel Vorynn](https://doomedzone.itch.io/the-white-beast-of-sel-vorynn):
  CC0/public-domain adventure reference candidate. Its art has separate license
  notes, so this repo does not vendor or adapt the art.
- [Open Adventure RPG](https://openadventurerpg.com/content-creation-licensing/):
  CC0 community-owned content fallback candidate.
- [One Page Dungeon Contest](https://www.dungeoncontest.com/submission-rules):
  CC BY-SA 4.0 content pool for possible later isolated examples.
- [Cairn SRD](https://cairnrpg.com/first-edition/cairn-srd/): CC BY-SA 4.0
  design comparison.
- [D100 Dungeon](https://store.steampowered.com/app/2148300/D100_Dungeon__Lost_Tome_of_Extraordinary_Rules/):
  closed commercial genre reference. Do not copy or port its protected content
  without permission.

## Current Content

The current `.dunge` files are intentionally generic:

- camp;
- white arch threshold;
- placeholder chamber;
- abstract starter tables for room segments, loot, and encounters.

Those names and descriptions are placeholders for exercising Dunge structure.
Before the example becomes a real adaptation, keep any borrowed mechanics or
content traceable to a source and license in this file.
