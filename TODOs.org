#+TITLE: Dunge Roadmap

* Phase 1: Interactive Fiction Foundation
- [X] Game object with named rooms and a starting room
- [X] Room descriptions, paragraph text, and numbered choices
- [X] Navigation between rooms, sub-scenes, and backtracking
- [X] Containers and placed items with interaction choices
- [X] Local entity state, references, conditional visibility, and simple effects
- [X] Load authored games from external data or user packages
- [X] Add save/load for current room, entity state, and world flags
- [X] Shared availability protocol for conditionally available and consumable nodes
- [X] First-class authored random tables with weighted, roll, deck, sequence, first-match, and bundle modes
- [X] Save/load state for table sequence and deck progress
- [X] Include player state in save/load once the player model exists

* Phase 1A: Content Data Foundations
- [X] Document the .dunge "what" vs Common Lisp "how" design boundary
- [X] Allow flat :when/:once/:id metadata on public :choice forms
- [X] Add tests for availability metadata and table source validation
- [X] Add a roll log and deterministic seed plumbing for table rolls
- [X] Add a public authoring guide for table result conventions

* Phase 1B: Adaptation Testbed
- [X] Research public-domain/CC0 dungeon RPG adaptation targets
- [X] Create adaptation skeleton with provenance notes and an authored entrance loop
- [X] Map adaptation loop to current Dunge support and engine gaps
- [X] Add dice utilities and CL character creation procedures for the adaptation
- [X] Add persistent generated room instances for the adaptation's first room
- [X] Resolve basic loot and exit table results into player/world mutations
- [X] Expand generated rooms into a small dungeon graph
- [X] Add encounter state and a minimal combat loop
- [ ] Add item-use table result procedures
- [ ] Add browser character and encounter panels

* Phase 2: Character And Inventory
- [X] Player state foundation with source validation and save/load
- [X] Inventory data model with stack helpers, slot accounting, Fatigue pressure, and Deprived checks
- [ ] Character creation flow with name, background, stats, HP, armor, gold, fate, and inventory
- [ ] Background starting gear matching the design document
- [ ] Inventory UI integration and gold handling
- [ ] Rest/recovery integration for Fatigue and Deprived status
- [ ] Item use effects for healing herbs, light sources, tools, spellbooks, scrolls, and relics

* Phase 3: Cairn Mechanics
- [X] Dice utilities and roll records
- [ ] STR/DEX/WIL saves
- [ ] Damage resolution: armor, HP, STR spillover, critical damage, and death
- [ ] Rest and recovery rules
- [ ] Fate points, scars, desperate escape, and true death

* Phase 4: Exploration Procedures
- [ ] Dungeon turn tracking
- [ ] Light source duration and darkness consequences
- [ ] Wandering monster checks
- [ ] Surprise, reaction rolls, and morale
- [ ] Searching, listening, doors, traps, and hidden exits
- [ ] Roll visibility setting and roll log

* Phase 5: Combat
- [ ] Encounter state and bestiary-backed enemies
- [ ] Combat choices for weapons, items, spells, fleeing, surrender, and improvised actions
- [ ] Group enemy / detachment handling
- [ ] Enemy behavior, morale, pursuit, and surrender
- [ ] Combat spell shortlist: Cure Wounds, Shield, Sleep, Charm, Pacify, Frenzy, Web

* Phase 6: Procedural Generation And Oracle
- [ ] Authored dungeon skeletons with procedural room details
- [ ] Monster, treasure, hazard, feature, and activity tables built on the table foundation
- [ ] Yes/no oracle with likelihood levels
- [ ] Twist, complication, spark, and random-event tables
- [ ] Seeding rules for previous-adventurer remains, journals, and regalia clues

* Phase 7: Town, Story, And Progression
- [ ] Town hub with guild, inn, blacksmith, merchant, temple, and mayor's mansion
- [ ] Rotating bounty board and reward loop
- [ ] Dunge regalia artifacts and lore fragments
- [ ] Previous-adventurer journals and milestone reveals
- [ ] Mayor meeting gates and alternate dialogue paths
- [ ] Final confrontation branches: slay Dunge, return the regalia, or die trying

* Phase 8: Presentation And Polish
- [ ] Compact, readable play transcript
- [ ] Character panel and inventory view
- [ ] Settings for roll visibility and logging
- [ ] Error handling for invalid choices and malformed content
- [ ] Example games that demonstrate rooms, containers, state, combat, and story progression
